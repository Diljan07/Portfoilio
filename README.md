💻 Run Locally

Clone or download the GitHub repository.

Open the project folder in VS Code.

Keep the HTML, CSS, and JavaScript files together.

Add the original images in their respective folders.

Open index.html using Live Server or a web browser.

Note: Tailwind CSS and Font Awesome require internet access. The current contact form uses a demo confirmation message rather than an email backend.

🌍 Deployment

This portfolio can be hosted for free using GitHub Pages.

Upload the project files to your GitHub repository.

Open Settings → Pages.

Choose Deploy from a branch.

Select main and /(root).

Save and open your published website.
